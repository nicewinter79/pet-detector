# 🐾 Pet Detector

A YOLO11-based object detection model that identifies and counts animals
(chicken, cow, dog, donkey, duckling, hamster, horse, koala, pigeon, rabbit,
sheep, toucan) in images, with a Streamlit dashboard for interactive testing.

Built as a step toward an automated farm-monitoring pipeline: detect animals
in footage → count them per class → surface results in a simple dashboard.

## 🧠 Model

- **Architecture:** YOLO11n (nano), trained with [ultralytics](https://docs.ultralytics.com/)
- **Dataset:** 12-class custom dataset annotated and exported via [Roboflow](https://roboflow.com/)
- **Training:** 100 epochs, image size 640, trained locally on an NVIDIA RTX 2050 (4GB VRAM)
- **Training time:** ~3.3 minutes (0.055 hours) on GPU

## 📊 Results

**Overall:** mAP50 = 0.729, mAP50-95 = 0.709

| Class  | Instances | mAP50-95 |
|--------|-----------|----------|
| dog    | 7         | 0.933    |
| horse  | 1         | 0.995    |
| koala  | 1         | 0.995    |
| sheep  | 1         | 0.995    |
| cow    | 4         | 0.196    |
| rabbit | 15        | 0.143    |

**Note on cow/rabbit:** these scored low on the validation split, but the
validation set only had 1–4 instances per class in some cases — too small
to be a reliable signal on its own. In practice, testing the model on a
completely new, unseen photo of a cow returned a **0.99 confidence**
correct detection — suggesting the model generalizes better than the
validation metric alone implies. Classes with very few training/validation
examples (rabbit, cow) would benefit most from additional training images
in a future iteration.

## 🚀 Usage

### 1. Set up environment
\`\`\`bash
python -m venv venv
venv\\Scripts\\activate        # Windows
pip install -r requirements.txt
\`\`\`

### 2. Run detection + counting from the command line
\`\`\`bash
python predict.py --source path/to/image.jpg
python predict.py --source path/to/folder_of_images/
python predict.py --source path/to/video.mp4
\`\`\`

Prints a per-class count summary and saves annotated output to `runs/detect/`.

### 3. Run the interactive dashboard
\`\`\`bash
streamlit run app_ui.py
\`\`\`
Opens a local web app where you can upload an image, adjust the confidence
threshold, and see live detection results with counts.
