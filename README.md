# 🐾 Pet Detector

A YOLO11-based object detection model that identifies and counts animals
(chicken, cow, dog, donkey, duckling, hamster, horse, koala, pigeon, rabbit,
sheep, toucan) in images, with a Streamlit dashboard for interactive testing.

Built as a step toward an automated farm-monitoring pipeline: detect animals
in footage → count them per class → surface results in a simple dashboard.

## 🧠 Model

- **Architecture:** YOLO11n (nano), trained with [ultralytics](https://docs.ultralytics.com/)
- **Dataset:** 12-class custom dataset annotated and exported via [Roboflow](https://roboflow.com/)
- **Training:** 100 epochs, image size 640, trained locally on an NVIDIA RTX 2050 (4GB VRAM)
- **Training time:** ~3.3 minutes (0.055 hours) on GPU

## 📊 Results

**Overall:** mAP50 = 0.729, mAP50-95 = 0.709

| Class  | Instances | mAP50-95 |
|--------|-----------|----------|
| dog    | 7         | 0.933    |
| horse  | 1         | 0.995    |
| koala  | 1         | 0.995    |
| sheep  | 1         | 0.995    |
| cow    | 4         | 0.196    |
| rabbit | 15        | 0.143    |

**Note on cow/rabbit:** these scored low on the validation split, but the
validation set only had 1–4 instances per class in some cases — too small
to be a reliable signal on its own. In practice, testing the model on a
completely new, unseen photo of a cow returned a **0.99 confidence**
correct detection — suggesting the model generalizes better than the
validation metric alone implies. Classes with very few training/validation
examples (rabbit, cow) would benefit most from additional training images
in a future iteration.

## 🚀 Usage

### 1. Set up environment
\`\`\`bash
python -m venv venv
venv\\Scripts\\activate        # Windows
pip install -r requirements.txt
\`\`\`

### 2. Run detection + counting from the command line
\`\`\`bash
python predict.py --source path/to/image.jpg
python predict.py --source path/to/folder_of_images/
python predict.py --source path/to/video.mp4
\`\`\`

Prints a per-class count summary and saves annotated output to `runs/detect/`.

### 3. Run the interactive dashboard
\`\`\`bash
streamlit run app_ui.py
\`\`\`
Opens a local web app where you can upload an image, adjust the confidence
threshold, and see live detection results with counts.

## Retraining Experiment (v2)

After the initial training run, I attempted to improve the weak `cow` and `rabbit` classes by adding 16 new images (from Pexels) and retraining on the expanded 92-image dataset.

**Result:** overall mAP50-95 dropped from 0.709 (v1) to 0.568 (v2) — the retrain performed worse, not better.

| Class | v1 mAP50-95 | v2 mAP50-95 |
|---|---|---|
| dog | 0.933 | 0.873 |
| horse | 0.995 | 0.000 |
| koala | 0.995 | 0.330 |
| sheep | 0.995 | 0.995 |
| cow | 0.196 | 0.147 |
| rabbit | 0.143 | 0.070 |

**Why this likely happened:** classes like horse, koala, and sheep only had 1 training example each in the original 76-image dataset. Adding 16 new images shifted the train/valid/test split, and by chance some of these already-fragile classes ended up with even fewer usable training examples in the new split — collapsing their scores rather than improving overall performance.

**Takeaway:** targeted data additions for one or two weak classes aren't enough on a very small, imbalanced dataset. A more effective fix would be expanding *all* underrepresented classes together (aiming for at least 10-15 examples per class) rather than patching individual weak spots one at a time.

**Decision:** kept the v1 model (`runs/detect/train`) as the production model, since it outperforms v2 overall. The v2 dataset and experiment are preserved for reference.

## Zone Detection (Proof of Concept)

Added `zone_detector.py`, which extends the tracking pipeline with point-in-rectangle geometry to detect when an animal enters or exits a defined zone — the same core technique used in commercial livestock/security systems for pasture-boundary alerts, restricted-area monitoring, or barn-entrance counting. The zone and detections are drawn on an annotated output video (`zone_output.mp4`) for visual verification.
